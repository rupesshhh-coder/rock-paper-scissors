# 🪨📄✂️ Rock Paper Scissors

A simple browser-based Rock Paper Scissors game built with **HTML, CSS and JavaScript**.

### 🎮 Live Demo

🔗 **[Play Rock Paper Scissors](https://rupesshhh-coder.github.io/rock-paper-scissors/)**

### ✨ Features

* 🪨📄✂️ Rock, Paper & Scissors choices
* 🎯 Random computer moves
* 🏆 Win & loss detection
* 🤝 Draw detection
* 📊 Score tracking

### 🛠️ Technologies

* HTML5
* CSS3
* JavaScript

### ▶️ Run Locally

Open `index.html` in any modern web browser.
